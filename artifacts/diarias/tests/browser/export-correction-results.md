The environment overrides below are runner-only: no browser, accessibility assertion, fixture guard or test is skipped. Do not add these overrides to application or production configuration.

```sh
MESA_ROOT=$(nix-instantiate --eval -E '(import <nixpkgs> {}).mesa.outPath' | tr -d '"')

__EGL_VENDOR_LIBRARY_FILENAMES="$MESA_ROOT/share/glvnd/egl_vendor.d/50_mesa.json" \
LIBGL_ALWAYS_SOFTWARE=1 \
CORRECTION_TEST_BASE_URL="http://localhost:80/" \
CORRECTION_CHROMIUM_EXECUTABLE_PATH=/repl/tools/bin/chromium \
pnpm --filter @workspace/diarias exec playwright test --config playwright.correction.config.ts
```

This is automated WebKit engine coverage, not a claim of testing Safari/iOS hardware or a physical virtual keyboard.
